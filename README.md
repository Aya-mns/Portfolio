# Full Stack Developer Portfolio
A modern and responsive full-stack developer portfolio built using ASP.NET Core MVC. This project showcases my technical skills, projects, and experience through a clean UI enhanced with smooth animations and interactive elements.

The portfolio highlights several projects, including a full-stack service marketplace (ProVision), a vehicle management system, and data analysis platforms. It demonstrates my ability to design and develop complete web applications, implement structured database solutions, and transform data into meaningful insights using business intelligence tools.

The application follows the MVC architecture, ensuring organized code structure, scalability, and maintainability, while providing a seamless and engaging user experience.
